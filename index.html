ⓘ 游戏规则

🎯 游戏目标

让你的手牌点数尽可能接近21点，但不能超过21点（超过就叫"爆牌"）。
你只需要和庄家比大小——比庄家大就赢，比庄家小就输，一样大算平局。

🃏 牌面点数

数字牌 2~10= 牌面数字
J、Q、K（人头牌）= 10点
A= 1点 或 11点（自动取对你最有利的值）

🎮 游戏流程

  1. 下注 → 点击筹码按钮，决定这局押多少
  2. 发牌 → 你和庄家各发2张牌，庄家只有1张明牌可见
  3. 操作 → 根据手牌选择要牌、停牌、加倍或分牌
  4. 庄家回合 → 庄家翻开暗牌，不到17点必须继续要牌
  5. 结算 → 比较点数，决定输赢

🕹️ 操作说明

🃏 要牌 Hit 再拿一张牌。可以多次要牌，直到满意或爆牌为止。
✋ 停牌 Stand 保持当前点数，不再要牌，轮到庄家行动。
💰 加倍 Double 追加一倍赌注，但只能再拿一张牌，然后自动停牌。
（仅限手牌刚好2张时使用）
✂️ 分牌 Split 当两张牌点数相同时，可以拆成两手独立的手牌，每手追加一份赌注。
最多可分3次（共4手）。分A后每手只补一张牌。
🛡️ 保险 Insurance 当庄家明牌是A时，你可以额外下注（最多为原赌注的一半），赌庄家有Blackjack。
如果庄家真是Blackjack，保险赢；不是则保险注输掉。

💵 赔率说明

情况赔率说明
普通赢1 : 1你的点数大于庄家（未爆牌），赢回等额赌注
Blackjack3 : 2起手两张牌直接21点（A+花牌/10），赢1.5倍赌注
庄家爆牌1 : 1庄家点数超过21点，你自动获胜
保险赢2 : 1庄家Blackjack时，保险注赢2倍（等于净赚1倍）
平局 Push—你和庄家点数相同，退回赌注，不输不赢
输-1 : 1点数小于庄家或自己爆牌，输掉赌注

💡 小贴士

  • 庄家必须遵守"17点规则"——不到17点必须继续要牌，达到17点及以上必须停牌
  • 软牌（含有A且A算11点不会爆）比硬牌更灵活，可以大胆要牌
  • 余额不足时会自动重置为 $1000，放心玩！
